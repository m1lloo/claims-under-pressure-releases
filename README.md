# Claims: Under Pressure

Official release repository for **Claims: Under Pressure**, a desktop insurance claims management simulation game.

This repository is used exclusively for distributing compiled releases and supporting automatic game updates.

## Downloads

The latest version of **Claims: Under Pressure** can be downloaded from the **Releases** section of this repository.

Release assets may include:

- Windows installer (`.exe`)
- Update metadata (`latest.yml`)
- Differential update files (`.blockmap`)

## Automatic Updates

Claims: Under Pressure includes a built-in automatic updater.

Installed versions of the game check this repository for new releases and can download and install supported updates directly from the application.

## Source Code

The source code for **Claims: Under Pressure** is maintained separately in a private repository and is **not included here**.

The automatically generated GitHub "Source code" archives for releases contain only the contents of this release repository. They do not contain the game's private source code.

## About the Game

**Claims: Under Pressure** puts you in control of a busy insurance claims operation.

Review incoming claims, investigate incidents, request evidence, make decisions, identify suspicious cases, manage your staff and keep an increasingly busy operation under control.

> **Run the claims desk. Investigate, decide, settle, and keep the backlog under control.**
