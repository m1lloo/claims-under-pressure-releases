# 📋 Claims: Under Pressure

> **Run the claims desk. Investigate, decide, settle, and keep the backlog under control.**

Welcome to the official release repository for **Claims: Under Pressure**, a desktop insurance claims management simulation game.

This repository is used exclusively for distributing compiled releases and powering automatic game updates.

## 🎮 Download

The latest version of **Claims: Under Pressure** is available from the **Releases** section of this repository.

Release assets may include:

- 🪟 Windows installer (`.exe`)
- 🔄 Automatic update metadata (`latest.yml`)
- 📦 Differential update files (`.blockmap`)

## 🔄 Automatic Updates

Claims: Under Pressure includes a built-in automatic updater.

Once installed, the game can check this repository for new versions, download supported updates and install them directly from the application.

## 🔒 Source Code

The source code for **Claims: Under Pressure** is maintained separately in a **private repository** and is not included here.

> ⚠️ **About GitHub's "Source code" downloads**
>
> GitHub automatically generates `.zip` and `.tar.gz` archives for each release. These contain only the contents of this public release repository and **do not contain the game's private source code**.

## 🏢 About the Game

Take control of a busy insurance claims operation where the work never really stops.

📥 **Handle incoming claims** across Motor, Home, Travel, Pet, Gadget and Major Loss.

🔎 **Investigate cases** by requesting evidence, reports and specialist input.

🚩 **Spot suspicious claims** and decide when cases need further investigation.

⚖️ **Make the call** by accepting, partially settling, negotiating or rejecting claims.

👥 **Manage your operation** as staffing, capacity and backlogs come under increasing pressure.

📈 **Watch the numbers** and balance customer outcomes against the performance of your operation.
